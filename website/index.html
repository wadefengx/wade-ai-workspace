Features

一个工作区,沉淀一切

从对话到知识到记忆,AI 原生地融入团队协作的每一个环节。

🧠

专家 Agent

无需 @AI 即可对话;@专家名 路由到指定专家。Agent 自带 emoji、角色、描述与 system prompt,可自由配置。

🔌

任意 LLM Provider

DeepSeek / OpenAI / Anthropic / OpenAI 兼容端点,或本地 Ollama。一键预设 + 连接测试,Workspace 级默认 Agent。

📚

RAG 知识库

递归切片 + Embedding + 向量检索。内容 hash 去重避免重复切片,回答以 [^n] 上标引用来源。

🗂️

分层记忆 L0→L3

对话 → 原子事实 → 场景 → 画像,单次 LLM 结构化抽取。渐进式披露:画像引导召回,事实按需下钻。

👥

团队与 RBAC

Workspace、频道、成员;全局管理员与 Workspace 角色双体系,权限清晰隔离。

📊

AI 组织仪表盘

AI 组织总览、反馈看板、Specs 与 Skills 浏览,团队 AI 资产一目了然。
