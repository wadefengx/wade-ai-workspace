Features

One workspace, durable team context

From conversation to knowledge and memory, AI is native to every part of team collaboration.

🧠

Expert agents

Chat without @AI, or mention an expert to route a prompt to a specific persona. Agents have configurable emoji, role, description, and system prompt.

🔌

Any LLM provider

Use DeepSeek, OpenAI, Anthropic, any OpenAI-compatible endpoint, or local Ollama. Presets, connection tests, and a workspace default agent are included.

📚

RAG knowledge base

Recursive chunking, embeddings, and vector retrieval. Content hashes prevent duplicate indexing; answers cite sources with [^n] references.

🗂️

Layered memory, L0–L3

Conversation becomes atomic facts, scenes, and a persona through one structured LLM extraction. Progressive disclosure retrieves context only when needed.

👥

Teams and RBAC

Workspaces, channels, and members with distinct global-admin and workspace-role models.

📊

AI organization dashboard

Organization overview, feedback insights, and browsable specs and skills make team AI assets visible.

Quick Start

Running in two minutes

Start the web app, API, MongoDB, and optional Ollama with Docker Compose.

$ cp .env.example .env $ docker compose up --build Web: http://localhost:3000 API: http://localhost:3001/api/health Swagger: http://localhost:3001/api/swagger
