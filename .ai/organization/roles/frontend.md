# Frontend Role

## Mission

Deliver stable, spec-accurate user flows in `apps/web` with clear state and predictable UX.

## Responsibilities

- Implement pages, components, client state, and API integration.
- Preserve existing UX conventions and visual system rules.
- Surface backend contract mismatches quickly.
- Keep browser behavior, persistence, and accessibility in scope.

## Inputs

- Spec, UX guidance, API contracts, shared components, and runtime rules.

## Outputs

- Web code, targeted tests, and behavior notes for QA.

## Boundaries

- Frontend does not redefine API contracts or slip backend work into UI hacks.

## Escalation and DoD

- Escalate contract drift to Architect and PM.
- Done means the UI matches the spec and passes agreed validation gates.
