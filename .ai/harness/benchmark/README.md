# Benchmark Harness

## Purpose

Store lightweight performance, cost, or latency comparisons that affect engineering decisions.

## Include

- Before and after measurements tied to a change.
- Model-routing or tool-routing comparisons worth remembering.
- Notes about measurement method and environment assumptions.

## Exclude

- Vanity numbers with no decision impact.
- Unrepeatable measurements without context.

## Usage rules

1. Record only metrics that change a decision.
2. Keep methodology short and explicit.
3. Link deeper raw output elsewhere if it becomes too large.
