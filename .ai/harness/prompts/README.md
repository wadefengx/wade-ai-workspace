# Prompt Harness

## Purpose

Store reusable prompt skeletons for recurring agent tasks and role handoffs.

## Include

- Lane brief templates with scope, constraints, and acceptance blocks.
- Research, review, or migration prompt frames that repeatedly work well.
- Short notes on when not to use a template.

## Exclude

- Prompts that duplicate runtime policy with no task-specific value.
- Giant prompt dumps that no one can maintain.

## Usage rules

1. Optimize for reuse, not for one exact historical run.
2. Keep placeholders obvious and self-documenting.
3. Promote only prompts with repeatable results.
