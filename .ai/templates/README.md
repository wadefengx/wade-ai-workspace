# Templates

## Purpose

Store template references that help new specs, briefs, or structured docs start from the same baseline.

## Current source

- The canonical phase spec template is mirrored at `.ai/specs/TEMPLATE.md`.

## Include

- Short pointers to canonical templates and when to use them.
- Future brief or ADR starter references once they stabilize.

## Exclude

- Duplicated full templates when a canonical source already exists.
- Temporary planning drafts.

## Usage rules

1. Prefer linking to one canonical template.
2. Add a new template only after repeated reuse proves it is stable.
