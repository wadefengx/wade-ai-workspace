# Engineering Knowledge

## Purpose

Store engineering reference that helps future changes land faster and safer.

## Include

- Operational constraints, integration notes, and proven patterns.
- Validation tips, local-first setup detail, and debugging guidance.
- Cross-module behaviors that are easy to forget.

## Exclude

- One-off task notes with no reuse value.
- Policy already captured more cleanly in `.ai/runtime/`.

## Curation rules

1. Write for the next engineer who did not see the original task.
2. Link to architecture, memory, or harness artifacts instead of duplicating them.
3. Prefer stable facts over step-by-step retrospectives.
