# Framework Knowledge

## Purpose

Store durable notes about the frameworks and libraries that shape repo conventions.

## Include

- Next.js, React, NestJS, Prisma, MongoDB, and Ant Design usage rules.
- Framework constraints that affect architecture or DX.
- Links between framework capabilities and repository patterns.

## Exclude

- Generic upstream docs copied verbatim.
- Repo-agnostic tutorials with no direct project impact.

## Curation rules

1. Summarize only the parts that change decisions in this repo.
2. Prefer concise deltas from upstream defaults.
3. Revisit entries when framework upgrades change local conventions.
