# Reference Knowledge

## Purpose

Store curated reference pointers that support decisions without bloating runtime context.

## Include

- External links, upstream docs, and canonical examples worth revisiting.
- Internal cross-links to specs, ADRs, and memory entries.
- Reference matrices that help compare tools or patterns.

## Exclude

- Unverified links or throwaway bookmarks.
- Content that should instead become a local skill or memory entry.

## Curation rules

1. Add a one-line reason for every reference.
2. Remove stale references when they no longer guide current decisions.
3. Prefer references that are stable, official, and directly actionable.
