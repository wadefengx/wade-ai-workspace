# ADR-002 — Local First

## Status

Accepted

## Background

The workspace targets fast local iteration with minimal dependency on remote services for core development and validation loops.

## Decision

Prefer local-first tooling, docker-compose bootstrap, local MongoDB replica set support, and local model/runtime options where practical.

## Consequences

- Development remains reproducible without always-on hosted infrastructure.
- Environment docs and mirrors become part of the engineering contract.
- Some integrations must explicitly document remote-service assumptions.

## Alternatives

- Cloud-first development with local support as a secondary path.
- Fully remote-only runtime for AI and persistence.
