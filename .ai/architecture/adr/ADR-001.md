# ADR-001 — AI Native Repository

## Status

Accepted

## Background

Repository context had grown across specs, skills, and a large AGENTS file, making runtime loading noisy and uneven.

## Decision

Adopt `.ai/` as the first-class organization layer for organization, runtime, workflows, memory, knowledge, architecture, harness, and migrated specs or skills.

## Consequences

- Runtime context becomes structured and easier to load in slices.
- Root `AGENTS.md` can stay short and act as an entrypoint.
- Migration needs compatibility with legacy `specs/` and `skills/` paths during rollout.

## Alternatives

- Keep expanding one root `AGENTS.md`.
- Split docs informally without a canonical root model.
