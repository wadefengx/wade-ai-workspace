# Research Workflow

## Input

- Open question, decision target, sources to inspect, and success criteria.

## Execution

1. Define the question narrowly enough to verify.
2. Search repository sources before reaching for outside material.
3. Cite exact files, specs, or commands that support each conclusion.
4. Separate confirmed facts from assumptions or follow-up questions.
5. Recommend the smallest next action that resolves the uncertainty.

## Output

- Findings with citations, risks, and a decision-ready summary.

## Validation

- Re-check the strongest claims against the original source before closing.

## Memory and skill

- Save durable conclusions to knowledge or memory and only extract reusable research playbooks as skills.
