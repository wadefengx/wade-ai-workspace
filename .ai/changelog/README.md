# Changelog Archive

## Purpose

Store longer-form historical release notes or archived phase summaries that do not belong in the short root `AGENTS.md` entrypoint.

## Usage

- Keep the root `AGENTS.md` limited to recent highlights only.
- Move older, detailed history here when the compressed entrypoint stops being useful.
- Link archived entries back to the relevant spec or ADR where possible.

## Current state

- Older history remains available in git history until dedicated archive notes are added.
